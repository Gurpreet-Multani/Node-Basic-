Welcome to the Basic Node.js HTTP Server!

This is the main landing page, served directly from the `index.html` file when a user navigates to the root path ( `/` ).

How This Works:

Your server uses Node.js and the `http` and `fs` modules to perform **static file serving** and **basic routing**.

  1. The browser requests the path **`/`**.
  2. Your `http.createServer` function sees `req.url === "/"`.
  3. It calls `HandleFiles("index.html", 200, res)`.
  4. The `fs.readFile` function loads this HTML file and sends it to the browser with an **HTTP 200 OK** status.

Use the links in the header to navigate to other pages!
